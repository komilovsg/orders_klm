# Веб-панель закупок КЛМ — Этап 1

Текущий этап запускает утверждённый HTML-прототип через сервер и добавляет серверный каркас: health-check, настройки, аудит, локальное/сетевое хранилище и ежедневные резервные копии.

## Запуск на Windows

Требуется Node.js 24 или новее. Docker и пароль на демонстрационном этапе не используются.

```powershell
npm.cmd test
npm.cmd start
```

Открыть `http://localhost:3000`.

Для других компьютеров локальной сети открыть `http://IP_КОМПЬЮТЕРА:3000`. В брандмауэре Windows должен быть разрешён входящий TCP-порт 3000.

## Хранилища

- Локальное: переменная `DATA_DIR`, по умолчанию `./data`.
- Сетевое: переменная `SHARED_DATA_DIR`, например `\\server\KLM\procurement-data`.
- Production БД для нескольких пользователей: PostgreSQL. На демонстрационном этапе используется встроенная SQLite.

## API Этапа 1

- `GET /api/health`
- `GET /api/architecture`
- `GET /api/audit`
- `POST /api/backup`

## Безопасность демонстрации

Авторизация временно отключена по решению заказчика. Публичная ссылка предоставляет доступ любому, кто её получил. До загрузки чувствительных данных в публичную демонстрацию необходимо включить авторизацию или ограничение туннеля.
